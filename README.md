# Habit Tracker — трекер привычек

Бэкенд-часть SPA веб-приложения для формирования полезных привычек, вдохновленная книгой Джеймса Клира «Атомные
привычки».
Система предоставляет API для управления привычками, поддерживает JWT-авторизацию, пагинацию, CORS и фоновую рассылку
напоминаний через интеграцию с Telegram (Celery + Redis).

---

## Стек технологий

* **Python:** 3.12+
* **Фреймворк:** Django 6.0+
* **API:** Django REST Framework (DRF)
* **База данных:** PostgreSQL
* **Асинхронные задачи:** Celery, Redis, `django-celery-beat`
* **Интеграция:** Telegram Bot API
* **Документация API:** `drf-spectacular` (OpenAPI 3)
* **Аутентификация:** `djangorestframework-simplejwt`

---

## Функционал

### 1. Управление пользователями (`users`)

* Кастомная модель пользователя с авторизацией по **Email**.
* Настроена JWT-аутентификация (получение и обновление токенов).
* Дополнительное поле `telegram_chat_id` для привязки Telegram бота.

### 2. Привычки (`habits`)

* Модель `Habit` включает параметры: действие, время, место, приятная/полезная привычка, связанная привычка,
  вознаграждение, периодичность и время выполнения.
* **Строгая валидация (Бизнес-логика):**
    * Исключено одновременное указание вознаграждения и связанной привычки.
    * Время выполнения ограничено 120 секундами.
    * В связанные привычки могут попадать только привычки с признаком `is_pleasant=True`.
    * Приятная привычка не может иметь вознаграждения или связанной привычки.
    * Привычка должна выполняться не реже 1 раза в 7 дней.
* **Ролевая модель:** Пользователь имеет полный CRUD-доступ **только к своим** привычкам.
* Доступен отдельный эндпоинт для просмотра списка **публичных** привычек других пользователей.
* Настроена пагинация (по 5 элементов на страницу).

### 3. Telegram-напоминания и Celery

* Интеграция с Telegram Bot API для отправки сообщений-напоминаний о привычках.
* Фоновые задачи и расписание (Celery Beat) настроены на динамическую рассылку уведомлений в зависимости от заданного
  времени (`time`) выполнения привычки.

## Основные эндпоинты API

### Документация
- `GET /api/schema/` — Выгрузка схемы OpenAPI.
- `GET /api/docs/swagger/` — Интерактивная документация Swagger UI.
- `GET /api/docs/redoc/` — Интерактивная документация ReDoc.

### Пользователи
- `POST /users/register/` — Регистрация пользователя.
- `POST /users/token/` — Получение JWT-токена.
- `POST /users/token/refresh/` — Обновление JWT-токена.

### Привычки
- `GET, POST /habits/` — Список привычек пользователя и создание новой привычки.
- `GET /habits/public/` — Список публичных привычек.
- `GET, PUT, PATCH, DELETE /habits/<id>/` — Детальная информация, обновление и удаление привычки.

## Установка и запуск

1. **Клонирование репозитория:**

```bash
git clone git@github.com:ivanitch/habit-tracker.git habit-tracker
cd habit-tracker
```

2. **Настройка окружения:**

```bsah
cp .env.example .env
uv sync
```

3. **Миграции:**

```bash
uv run python manage.py makemigrations
uv run python manage.py migrate
```


4. **Создание суперпользователя:**

```bash
uv run python manage.py createsuperuser
```

5. **Запуск сервера**

```bash
uv run python manage.py runserver

# или
./server.sh
```

---

6. **Запуск Celery (в отдельных окнах терминала)**

```bash
celery -A config worker --loglevel=info
celery -A config beat --loglevel=info
````

---

7. **Тестирование и покрытие кодом**

```bash
uv run python manage.py test

uv run coverage run --source='.' manage.py test
uv run coverage report
```
